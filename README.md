# 正誤トレーナー Web版

iOS版「正誤トレーナー」と同じ仕組みを、ブラウザで動くWebアプリ（PWA）にしたものです。
GitHub Pagesで公開すれば、AndroidでもiPhoneでも、ホーム画面に追加してアプリのように使えます。
データ（問題集・成績・統計）は、開いた端末のブラウザの中にだけ保存されます。このリポジトリに学習データは含まれません。

## GitHub Pagesで公開する手順（初回だけ）

1. このリポジトリの **Settings** → **Pages** を開く
2. **Build and deployment** の Source で **Deploy from a branch** を選ぶ
3. Branch で **main** / **/ (root)** を選んで **Save**
4. 数分待つと、上部に公開URL（`https://gata272.github.io/seigotrainer-web/`）が表示されます

## ホーム画面に追加

- Android（Chrome）: 公開URLを開く → メニュー ︙ →「ホーム画面に追加」または「アプリをインストール」
- iPhone（Safari）: 公開URLを開く → 共有ボタン →「ホーム画面に追加」

追加後はオフラインでも起動できます（Service Workerが本体をキャッシュします）。

## 使い方（iOS版と共通）

- リスト画面の「＋ 追加」からCSV（番号,表面,裏面,解説）を読み込みます。ZIP（中のCSVがそれぞれリストになります）にも対応
- 裏面が ①〜⑥ や ○/× の問題はタップで自動判定、それ以外は「答えと解説を見る」→自己判定
- 値（スコア）は正解 +1 / 不正解 -1。マイナスの問題が「間違えた問題」です
- 絞り込み：セクション / 範囲（問題番号）/ スター付きのみ / 値の範囲（既定はマイナスのみ）
- スワイプ：右へ＝前の問題（問題画面で開く）、左へ＝解説を見ずに次の問題へ
- 統計はデフォルトOFF。統計タブでオンにすると、その日から日ごとに記録されます
- リスト画面の「書き出し」で全データのバックアップ（JSON）が取れます。「読み込み」で復元・端末間の移動ができます

## ファイル構成

- `index.html` — アプリ本体（画面・ロジックすべて）
- `manifest.webmanifest` / `sw.js` — ホーム画面追加・オフライン用
- `icons/` — アイコン
- `.nojekyll` — GitHub Pages用

## 更新方法

`index.html` などを新しい版に差し替えてpushすると、Pagesに自動で反映されます。
Service Workerのキャッシュを切り替えるときは、`sw.js` の `CACHE_NAME` の版番号を上げてください。
